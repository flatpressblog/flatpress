
Automatic mode is deliberately conservative:
- Pretty is selected automatically only when FlatPress receives a positive rewrite signal (the generated Apache marker, IIS rewrite signal, or a routed request that actually reached index.php).
- A generic REDIRECT_URL is not sufficient because shared hosts may set it for unrelated platform redirects.
- If rewrite support cannot be proven, Automatic falls back to HTTP Get.
- In the admin panel, each green check is backed by a real authenticated same-origin probe. PATH_INFO, HTTP Get and Pretty/rewrite are marked only when the corresponding URL form actually reaches FlatPress on the current web host.
- Pretty can always be selected explicitly for NGINX or other servers configured outside .htaccess.

Note: If you cannot find or edit nginx.conf, as is the case with ISPs, check whether your web hosting package includes a WordPress option. It is worth activating and testing this option.
The following examples assume that FlatPress is located in a subdirectory <FlatPress instance> of the root directory.

NGINX configuration (etc/nginx/nginx.conf) for Automatic, Path Info, HTTP Get and Pretty
========================================================================================

# Pretty (recommended)
location /<FlatPress instance>/ {
	root /var/www;
	try_files $uri $uri/ /<FlatPress instance>/index.php$is_args$args;
}

# Execute only real PHP files under the instance
location ~ ^/<FlatPress instance>/.*\.php$ {
	root /var/www;

	# important: only run genuine files
	try_files $uri = 404;

	include fastcgi_params;
	fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
	fastcgi_param QUERY_STRING $query_string;
	fastcgi_pass unix:/run/php/php8.4-fpm.sock; # adjust
}

# Optional sitemap aliases
location = /<FlatPress instance>/sitemap {
	rewrite ^ /<FlatPress instance>/sitemap.php last;
}
location = /<FlatPress instance>/sitemap.xml {
	rewrite ^ /<FlatPress instance>/sitemap.php last;
}

# Deny .ht* (and similar)
location ~ ^/<FlatPress instance>/\.ht {
	deny all;
}

# PATH_INFO (only if "Path Info" mode is used)
location ~ ^/<FlatPress instance>/index\.php(/|$) {
	root /var/www;

	include fastcgi_params;
	fastcgi_split_path_info ^(.+\.php)(/.*)$;

	# only execute real index.php
	try_files $fastcgi_script_name = 404;

	fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
	fastcgi_param PATH_INFO $fastcgi_path_info;
	fastcgi_param QUERY_STRING $query_string;
	fastcgi_pass unix:/run/php/php8.4-fpm.sock; # adjust
}


WordPress web hosting config for NGINX servers for Automatic, HTTP Get and Pretty
=================================================================================
location / {
	try_files $uri $uri/ /<FlatPress instance>/index.php?$args;
}


Apache configuration (.htaccess in FlatPress root directory)
============================================================

# BEGIN FlatPress PrettyURLs
AddType application/x-httpd-php .php
Options -Indexes

<IfModule mod_headers.c>
	Header unset X-Powered-By
</IfModule>

<IfModule mod_rewrite.c>
	RewriteEngine On
	RewriteBase /<FlatPress instance>/
	RewriteRule ^ - [E=FLATPRESS_PRETTYURLS:1]

	RewriteRule ^\.htaccess$ - [F]

	RewriteRule ^\.setup\.php$ - [F,L]
	RewriteRule ^\.setup/ - [F,L]

	RewriteRule ^sitemap\.xml$ /<FlatPress instance>/sitemap.php [L]
	RewriteRule ^sitemap$ /<FlatPress instance>/sitemap.php [L]

	RewriteRule ^index\.php/__flatpress_prettyurls_probe__/$ - [L]

	RewriteCond %{REQUEST_FILENAME} !-f
	RewriteCond %{REQUEST_FILENAME} !-d

	RewriteRule . /<FlatPress instance>/index.php [L]
</IfModule>
# END FlatPress PrettyURLs

# HTTP compression and caching for static assets; PHP-FPM-compatible
<IfModule mod_deflate.c>
	# Compress only text-based formats.
	AddOutputFilterByType DEFLATE text/html
	AddOutputFilterByType DEFLATE text/plain
	AddOutputFilterByType DEFLATE text/css
	AddOutputFilterByType DEFLATE text/javascript
	AddOutputFilterByType DEFLATE text/xml
	AddOutputFilterByType DEFLATE text/vtt

	AddOutputFilterByType DEFLATE application/javascript
	AddOutputFilterByType DEFLATE application/json
	AddOutputFilterByType DEFLATE application/ld+json
	AddOutputFilterByType DEFLATE application/manifest+json
	AddOutputFilterByType DEFLATE application/xml
	AddOutputFilterByType DEFLATE application/xhtml+xml
	AddOutputFilterByType DEFLATE application/rss+xml
	AddOutputFilterByType DEFLATE application/atom+xml

	AddOutputFilterByType DEFLATE image/svg+xml
</IfModule>

<IfModule mod_headers.c>
	# Without a version parameter, cache for only one week.
	<FilesMatch "\.(?:css|js|mjs|svg|gif|png|jpe?g|webp|avif|ico|woff2?|ttf|otf|eot)$">
		Header set Cache-Control "public, max-age=604800"

		# FlatPress adds ?v= to many theme and plugin assets...
		# These files may be cached unchanged for one year.
		Header set Cache-Control "public, max-age=31536000, immutable" \
			"expr=%{QUERY_STRING} =~ m#(^|&)v=[^&]+(&|$)#"
	</FilesMatch>
</IfModule>


PrettyURLs capability checks
============================

The green checks in the PrettyURLs admin panel are verified with authenticated,
same-origin browser requests. PATH Info is marked only if the web server actually
passes the probe suffix to index.php as PATH_INFO/ORIG_PATH_INFO. Pretty is marked
only if a clean path without index.php actually reaches the FlatPress front
controller. HTTP Get is marked only if the generated ?u=/... request reaches
index.php with the expected route parameter intact.
